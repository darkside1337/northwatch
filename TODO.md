# Northwatch — Implementation TODO

Phased build plan, ordered to follow the core customer journey:

```
Homepage → Browse → Product Page → Variant → Add to Cart
  → Checkout → Shipping → Payment → Confirmation → Account / Order History
```

Phase 0 is infrastructure every later phase depends on. Phases 1–7 roughly track the journey above. Phase 8 is hardening, Phase 9 is Phase-2 scope (explicitly out of v1). Check off items as you go — each phase should leave the app in a runnable state.
